How to publish quickly on Cloudflare Pages
------------------------------------------
1. Unzip this package.
2. Log in to Cloudflare.
3. Open Workers & Pages.
4. Create a new Pages project using Direct Upload.
5. Upload the CONTENTS of the hartmutsailing_site folder, with index.html at the root.
6. Cloudflare will provide a temporary *.pages.dev address.
7. Test the website there before connecting hartmutsailing.com.
8. Later add hartmutsailing.com as a Custom Domain and update DNS at Wix as instructed by Cloudflare.

Do not change Wix DNS until the temporary Cloudflare site works correctly.
